ALARM SOUNDS
============

Built in (original synthesized tones, free to use):
  soft_chime.wav, rising_bells.wav, classic_beep.wav

Islamic ringtones - ADD YOUR OWN FILES HERE
-------------------------------------------
Copy audio files into this folder using EXACTLY these names
(extension can be mp3, m4a, wav, ogg or aac):

  azan_makkah.mp3         -> "Azan (Makkah)"
  azan_madinah.mp3        -> "Azan (Madinah)"
  takbeer.mp3             -> "Takbeer"
  quran_recitation.mp3    -> "Quran recitation"
  morning_dua.mp3         -> "Morning dua"

The app detects the files automatically. Ringtones whose file is missing
appear greyed out in the picker, and alarms fall back to "Soft chime".

IMPORTANT - copyright
---------------------
Recordings of azan and Quran recitation are usually copyrighted by the
reciter / publisher. Use only audio you recorded yourself, audio you have
written permission to use, or audio released under a licence that allows
use inside an app. Google Play can reject or remove apps that use
unlicensed recordings.

Keep each file short and loopable (10-60 seconds works well for an alarm)
and keep the total app size reasonable.
